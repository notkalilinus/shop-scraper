→ Install from: https://www.oracle.com/java/technologies/downloads/

**"Permission denied"**
→ Right-click BUILD.bat → Run as Administrator

**"Build takes too long"**
→ First build is slow (downloads ~500MB)
→ Subsequent builds are fast (~1-2 min)

**"Still failing"**
→ Open PowerShell and run:
```powershell

.\gradlew.bat clean build
```
