## 🎯 KEY FEATURES

### State Machine
```
IDLE → OPENING_SHOP → SCANNING_MAIN → OPENING_CATEGORY
→ SCANNING_CATEGORY → NEXT_PAGE (repeat) → COMPLETE
```

### Dual Modes
- **Visual**: GUI visible, mouse clicks, testing
- **Packet**: Silent, network packets, production

### Rate Limiting
- Configurable delays (default 250ms)
- Prevents anti-cheat kicks
- FIFO task queue

### Price Extraction
- Regex: `(?i)(?:Buy|Value|Price)[\s:]*[$]?([\d,]+...)`
- Handles: 1000, 1K, 1.5M formats
- Features: Color codes, flexibility
